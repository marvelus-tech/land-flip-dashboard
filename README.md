# Land Flip Dashboard — Land & Light (Apple HIG)

Premium redesign completed.

## Design System
- **Primary accent**: #2C3E2D (deep forest green)
- **Gold highlight**: #C5A46E (used sparingly — metrics, focus pill)
- **Background**: #F9F7F2
- **Surfaces**: #FFFFFF
- **Typography**: SF Pro Display / system stack, heavy size & weight contrast
- **Spacing**: Generous (48–64px page padding, 22px row padding)

## Imagery Treatment
- Subtle aerial landscape (very low opacity) in header
- Refined close-up stakes photo used as small decorative land marker

## Key Improvements
- Completely replaced old dense purple theme
- Calm, confident, expensive aesthetic
- State-grouped builder rows with minimal visual noise
- Icon actions appear only on interaction
- Gold accent only on the most important metric (Active)
- Extremely restrained state filters
- All 60 original builders preserved exactly

## Files
- `index.html` — self-contained single file
- `assets/images/` — 4 high-quality land images (used subtly)

Built to Apple Human Interface Guidelines standards.
